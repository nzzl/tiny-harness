# Code of conduct

Be respectful in issues, pull requests, reviews, and other project discussions.
People with different backgrounds and experience levels are welcome.

- Discuss the work and explain disagreements without personal attacks.
- Accept constructive feedback and respect maintainers' scope decisions.
- Do not harass, threaten, discriminate, spam, or publish private information.

The maintainer, [@nzzl](https://github.com/nzzl), may edit or remove inappropriate
content, close or lock discussions, and restrict participation when necessary.

For a public moderation request, mention @nzzl in the relevant issue or pull
request. Do not post sensitive details publicly. To report abuse privately to
GitHub Support, use GitHub's Report content / Report abuse tools or its
[abuse reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Those reports go to GitHub, not to the project maintainer. This project does not
currently provide a separate private conduct-reporting inbox.

For software vulnerabilities, use the separate [security reporting route](SECURITY.md).
